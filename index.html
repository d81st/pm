⚠️ Важно о безопасности
Данные хранятся только в зашифрованном файле на вашем диске. Делайте резервные копии через «Экспорт». Это не замена KeePassXC. Не используйте для банковских аккаунтов. Если кто-то подменит сам HTML-файл, введённый пароль может быть украден. Храните свою копию страницы отдельно и не открывайте её из чужих источников.
Хранилище в GitHub изменили на другом устройстве. Автосохранение остановлено, чтобы не затереть чужие изменения.
Автосохранение недоступно. После изменений скачайте обновлённый файл хранилища.

Подробности

Категории

Группы, по которым записи раскладываются на главной странице. Названия хранятся только внутри зашифрованного файла. При удалении категории записи не удаляются, а переезжают в «Другое».

Синхронизация с GitHub

Хранилище лежит в вашем приватном репозитории и сохраняется туда после каждого изменения. Каждое сохранение — коммит, поэтому любую прошлую версию можно восстановить. Если хранилище изменят на другом устройстве, страница не затрёт эти изменения молча.

Подключено:

Настройки (вместе с токеном) хранятся и внутри зашифрованного хранилища: на новом устройстве достаточно открыть файл хранилища — страница сама предложит включить синхронизацию.

Токен нужен только с доступом к этому репозиторию и правом Contents: Read and write. Он хранится зашифрованным мастер-паролем: в этом браузере и внутри самого хранилища (для других устройств). Отправляется только на api.github.com.
