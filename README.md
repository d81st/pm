# pm — офлайн-менеджер паролей

Одностраничное приложение: `index.html`, без внешних зависимостей.
Шифрование: AES-256-GCM + Argon2id (64 МиБ, t=3, p=1). Хранилище — зашифрованный JSON.

Страница: https://d81st.github.io/pm/

В этом репозитории **нет никаких данных** — только код. Само хранилище лежит в отдельном приватном репозитории
и синхронизируется страницей через GitHub API (Настройки → «Синхронизация с GitHub»).

Проверка целостности: SHA-256 файла `index.html` можно сверить с хэшем, записанным у вас отдельно.

## Если правите код вручную

Страница выполняет только те встроенные скрипты, чей SHA-256 записан в её Content-Security-Policy.
После любой правки кода внутри `<script>` запустите:

    python3 tools/update-csp.py index.html

Иначе браузер заблокирует изменённый скрипт и страница не откроется. Номер версии показан на экране входа.
